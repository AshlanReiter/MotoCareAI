# MotoCare AI — Complete Owner/Staff Interface Prototype

This is a front-end-only prototype for the proposed MotoCare AI motorcycle repair and shop management system.

## Files

motocare-ai/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
└── pages/
    └── (reserved)

## Run

Open `index.html` in a browser.

No backend, database, server, framework, or external library is required.

## What is included

- Dashboard
- Customers: list, add/edit, details
- Motorcycles: list, add/edit, details
- Appointments: list, calendar, add/edit, details
- Repairs & Services: list, new repair, details, status, mechanic assignment, parts
- Mechanics: list, add/edit, details
- Inventory: list, add/edit, details, stock updates
- Sales & POS: products, cart, quantity controls, payment flow
- Reports: dashboard and detailed report screens
- Search/filter controls
- Working prototype modals/forms
- Sample data
- Responsive layout

## Important

The interactions are intentionally prototype interactions. Data exists only in the browser session and is reset when the page is refreshed.

This interface is intended to become the reference blueprint for the Figma design.
